# Visual asset attribution

This file records third-party visual material that is still shipped, including files that are not
currently loaded at runtime. Do not remove a notice merely because an asset is temporarily unused.

## Original precinct art

`tilesets/precinct-tileset.png` and `maps/brooklyn99.tmj` are original procedural art and
layout generated by `tools/gen-b99-map.cjs`. They do not include or derive from LimeZu art.

## Pixel art — LimeZu (IMPORTANT: non-commercial license)

The legacy office tilesets (all tileset PNGs except `precinct-tileset.png`) and four base character sheets
(`characters/{Adam,Alex,Amelia,Bob}_walk.png`) are LimeZu pixel-art assets, distributed under
the **LimeZu FREE VERSION license** (see `tilesets/LIMEZUASSETS-LICENSE.txt`):

- May be used and edited in non-commercial projects only.
- May not be used or edited in commercial projects, and edited sprites may not be resold.

The current procedural portraits and walking cast are drawn in code and do not load these four
character sheets. The sheets are nevertheless present in the repository and distribution, so
their LimeZu notice and non-commercial restriction still apply. **Before any commercial use,
replace all covered assets or obtain an appropriate paid LimeZu license.**

## Maps and floor renderer

`maps/office.tmj` and `maps/lobby.tmj` were vendored from
[`shahar061/the-office`](https://github.com/shahar061/the-office), whose project code is ISC, and
use the LimeZu tilesets above. `maps/brooklyn99.tmj` is generated in this project by
`tools/gen-b99-map.cjs` and uses only the original `precinct-tileset.png` atlas.

Parts of the Pixi.js floor renderer and movement implementation are also ported or adapted from
`shahar061/the-office`; source files retain inline provenance comments.
