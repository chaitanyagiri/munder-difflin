# Archived Upstream Website

Most files in this directory are retained snapshots of the Munder Difflin website and blog. They
remain for upstream history and attribution; they are not The Precinct's active product website.

The upstream custom-domain binding and automatic blog publication workflow are intentionally not
enabled in this fork. Current project and release information lives in the repository root
[`README.md`](../README.md), [`CHANGELOG.md`](../CHANGELOG.md), and [`RELEASE.md`](../RELEASE.md).
